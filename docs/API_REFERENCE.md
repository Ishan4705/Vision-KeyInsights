## Endpoints

### Generate Thumbnail

Create a new AI-generated thumbnail.

#### `POST /api/generate-thumbnail`

**Authentication:** Required

**Content-Type:** `multipart/form-data`

**Request Body:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `userInput` | string | Yes | Text prompt describing the thumbnail |
| `refImage` | File | No | Reference image for style guidance |
| `faceImage` | File | No | Face image for personalization (future) |

**Example Request:**

```typescript
const formData = new FormData();
formData.append('userInput', 'React Tutorial: Build App in 1 Hour');
formData.append('refImage', fileInput.files[0]); // optional

const response = await fetch('/api/generate-thumbnail', {
  method: 'POST',
  body: formData,
});

const data = await response.json();
console.log(data.runId); // Inngest job ID
```

**Response:**

```json
{
  "runId": "01HGX7Z9K8QVZXJQK7YPQVN7N8"
}
```

**Status Codes:**

| Code | Description |
|------|-------------|
| 200 | Success — Job queued |
| 400 | Bad Request — Missing required fields |
| 401 | Unauthorized — Not signed in |
| 413 | Payload Too Large — File size exceeds limit |
| 500 | Internal Server Error |

**Authentication:** Required

**Content-Type:** `application/json`

**Request Body:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `userInput` | string | Yes | Topic or title for content generation |

### Outlier Detection

Analyze YouTube videos to identify viral outliers using statistical methods.

#### `GET /api/outlier`

**Authentication:** Required

**Query Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `query` | string | Yes | Search query for analysis |

**Example Request:**

```typescript
const response = await fetch(
  `/api/outlier?query=${encodeURIComponent('python programming')}`
);
const data = await response.json();
```

**Response:**

```json
[
  {
    "id": "abc123",
    "title": "Python Tutorial - Full Course",
    "thumbnail": "https://i.ytimg.com/vi/.../hqdefault.jpg",
    "channelTitle": "freeCodeCamp",
    "publishTime": "2026-01-10T00:00:00.000Z",
    "viewCount": "5000000",
    "likeCount": "100000",
    "commentCount": "5000",
    "viewPerDay": 50000,
    "engagementRate": 2.10,
    "smartScore": 1.835,
    "isOutlier": true,
    "outlierScore": 3.45
  }
]
```

**Outlier Detection Algorithm:**
- Uses **IQR (Interquartile Range)** method on view counts
- **Smart Score** = `(viewCount/avgViews) × 0.5 + (viewsPerDay/maxViewsPerDay) × 0.3 + (engagementRate/maxEngagementRate) × 0.2`
- Videos with views > Q3 + 1.5×IQR or < Q1 - 1.5×IQR are flagged as outliers

**Status Codes:**

| Code | Description |
|------|-------------|
| 200 | Success |
| 500 | Internal Server Error |

## Background Jobs (Inngest)

### Polling for Job Status

All async workflows return a `runId` that can be polled for status:

```typescript
import { RunStatus } from '@/services/GlobalApi';

// Poll every 3 seconds
const checkStatus = async (runId: string) => {
  const runStatus = await RunStatus(runId);
  if (runStatus && runStatus[0]) {
    const { status, output } = runStatus[0];
    if (status === 'Completed') {
      // Process output
    } else if (status === 'Failed') {
      // Handle error
    }
  }
};
```

### Registered Functions

| Function | Event | Steps | Avg Duration |
|----------|-------|-------|--------------|
| `ai/generate-thumbnail` | `ai/generate-thumbnail` | 5 | 15–30s |
| `ai/generate-content` | `ai/generate-content` | 4 | 30–90s |
| `ai/get-trending-keywords` | `ai/get-trending-keywords` | 4 | 10–20s |

### Retry Policy
- Automatic retries on transient failures
- Max 3 attempts per step
- Exponential backoff
- Rate limit retry with configurable wait (Replicate 429 handling)

## Error Responses

All error responses follow this format:

```json
{
  "error": "Error message",
  "details": "Additional context (optional)"
}
```

### Common Error Codes

| Code | Description | Resolution |
|------|-------------|------------|
| `400` | Missing or invalid parameters | Check request body/query |
| `401` | User not authenticated | Sign in first |
| `500` | Internal server error / external API failure | Retry later |

- Free tier (< $5 credit): 6 requests/minute

- Depends on your plan

- Default quota: 10,000 units/day
- Search request: 100 units each
- Video details: 1 unit per video

- Transformations: Based on plan

### Bright Data
- Based on your zone configuration
- Check [Bright Data dashboard](https://brightdata.com/cp)
