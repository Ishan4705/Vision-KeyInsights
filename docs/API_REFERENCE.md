## Endpoints

### Generate Thumbnail

Create a new AI-generated thumbnail.

#### `POST /api/generate-thumbnail`

**Authentication:** Required

**Content-Type:** `multipart/form-data`

**Request Body:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `userInput` | string | Yes | Text prompt describing the thumbnail |
| `refImage` | File | No | Reference image for style guidance |
| `faceImage` | File | No | Face image for personalization (future) |

**Example Request:**

```typescript
const formData = new FormData();
formData.append('userInput', 'React Tutorial: Build App in 1 Hour');
formData.append('refImage', fileInput.files[0]); // optional

const response = await fetch('/api/generate-thumbnail', {
  method: 'POST',
  body: formData,
});

const data = await response.json();
console.log(data.runId); // Inngest job ID
```

**Response:**

```json
{
  "runId": "01HGX7Z9K8QVZXJQK7YPQVN7N8"
}
```

**Status Codes:**

| Code | Description |
|------|-------------|
| 200 | Success - Job queued |
| 400 | Bad Request - Missing required fields |
| 401 | Unauthorized - Not signed in |
| 413 | Payload Too Large - File size exceeds limit |
| 500 | Internal Server Error |

## Background Jobs (Inngest)

### Thumbnail Generation Job

**Event Name:** `ai/generate-thumbnail`

**Triggered By:** POST to `/api/generate-thumbnail`

**Job Steps:**

1. **UploadImage** - Upload reference image to ImageKit
2. **GenerateThumbnailPrompt** - Generate optimized prompt with OpenRouter
3. **Generate Image** - Create thumbnail with Replicate
4. **Upload Thumbnail** - Save final thumbnail to ImageKit
5. **SaveToDB** - Store metadata in database

**Average Duration:** 15-30 seconds

**Retry Policy:**
- Automatic retries on transient failures
- Max 3 attempts per step
- Exponential backoff

## Error Responses

All error responses follow this format:

```json
{
  "error": "Error message",
  "code": "ERROR_CODE",
  "details": {} // Optional additional information
}
```

### Common Error Codes

| Code | Description | Resolution |
|------|-------------|------------|
| `UNAUTHORIZED` | User not authenticated | Sign in first |
| `INVALID_INPUT` | Missing or invalid parameters | Check request body |
| `FILE_TOO_LARGE` | Uploaded file exceeds limit | Reduce file size |
| `RATE_LIMIT` | Too many requests | Wait and retry |
| `EXTERNAL_API_ERROR` | Third-party service failed | Retry later |

## SDK Examples

### JavaScript/TypeScript

```typescript
// Generate thumbnail
async function generateThumbnail(prompt: string, refImage?: File) {
  const formData = new FormData();
  formData.append('userInput', prompt);
  if (refImage) {
    formData.append('refImage', refImage);
  }

  const response = await fetch('/api/generate-thumbnail', {
    method: 'POST',
    body: formData,
  });

  if (!response.ok) {
    throw new Error('Failed to generate thumbnail');
  }

  return response.json();
}

// Get thumbnail history
async function getThumbnails() {
  const response = await fetch('/api/generate-thumbnail');
  const data = await response.json();
  return data.result;
}
```

### React Hook

```typescript
import { useState } from 'react';
import axios from 'axios';

export function useThumbnailGenerator() {
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const generate = async (userInput: string, refImage?: File) => {
    setLoading(true);
    setError(null);

    try {
      const formData = new FormData();
      formData.append('userInput', userInput);
      if (refImage) {
        formData.append('refImage', refImage);
      }

      const response = await axios.post('/api/generate-thumbnail', formData);
      return response.data;
    } catch (err) {
      setError(err.message);
      throw err;
    } finally {
      setLoading(false);
    }
  };

  return { generate, loading, error };
}
```
