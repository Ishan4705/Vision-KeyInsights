## ✨ What's New in v2.0.0

- **AI Content Generator** — Generate SEO-optimized titles, descriptions, tags, and thumbnail prompts
- **Trending Keywords** — Discover high-ranking SEO keywords from Google & YouTube search data
- **Thumbnail Search** — Search and browse YouTube thumbnails with engagement metrics
- **Outlier Detection** — Identify viral outlier videos using statistical analysis (IQR method)
- **New Database Tables** — `AiContent` and `TrendingKeywords` tables added
- **New Integrations** — YouTube Data API v3, Bright Data web scraping
